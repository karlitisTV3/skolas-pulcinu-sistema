# Skolas pulciņu sistēma

## Apraksts
Šī ir Flask tīmekļa lietotne, kas ļauj skolēniem reģistrēties, pieslēgties un pieteikties skolas pulciņiem. Administrators var izveidot un pārvaldīt pulciņus un redzēt pieteikumus.

## Tehnoloģijas
Python
Flask
SQLite
HTML / CSS

## Plānošana
Wireframe un ERD shēma tika izstrādāta diagrams.net programmā.
